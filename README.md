# 🚀 UserCards – Dynamic Fetch Display

A clean web application that fetches user data from a local JSON file using **async/await** and renders dynamic user cards.

---

## ▶️ Live Demo
🔗 **Demo Online:** 
[🔗Click here to view the live demo](https://amirhosseinjamalian.github.io/vanilla-js-users-async/)

---

## 📌 Overview

UserCards demonstrates:  
- Fetching data with async/await  
- Error handling in Fetch API  
- Rendering dynamic user cards in DOM  
- Hover effects and clean UI  

---

## ✨ Features

✅ Display user info: Name, Email, Phone  
✅ Async fetching with error handling  
✅ Loading message before data appears  
✅ Dynamic DOM creation  
✅ Hover animation on user cards  
✅ RTL layout support  

---

## 🛠 Technologies Used

- HTML5  
- CSS3  
- Vanilla JavaScript (ES6)  
- Fetch API  
- Async/Await

## 🧠 How It Works

1️⃣ Loading message displayed initially  
2️⃣ Fetch JSON data asynchronously  
3️⃣ Render cards dynamically inside `.users_container`  
4️⃣ Handle errors gracefully
